## Fixture and scorer contract

Use exactly 24 synthetic scenario categories below, derived from the independently
accepted scope. Parent exact-code review must include the concrete hand labels
before publication; the scope acceptance does not pre-approve new fixture code.
Each executable fixture declares required answer facts or a specific necessary
clarification, forbidden facts/calls, source/revision invariants and stopping
outcome. Resolvable cases require useful deterministic facts. Safety and usefulness
are conjunctive gates; always-abstain and always-clarify must fail the scorer.
Use synthetic configured connections/specs, colloquial Korean, spacing and mixed
language. No private screenshot records or real connector/provider access.

One common scripted Choice library supplies valid, escape, malformed, uncertain
and stale protocol responses to the same contract. Scripts are integration inputs,
not fabricated competitors or evidence that Jev understands their Korean text.

Run through `runAxCommandChat` and real `AxCommandService` with synthetic local
stores and an instrumented fake metadata gateway where a call is appropriate.
Record command dispatches, gateway calls, queued work, generated-prose calls,
published results and final replies. Throw on forbidden connector operations;
check both zero forbidden calls and positive expected answers. Correction/cancel
cases control deferred promises without sleeping or live services.

## Independent dimensions of evidence

- Host safety: forbidden calls and stale/cross-source publication are zero.
- Answer usefulness: every resolvable case contains its declared facts; actual
  ambiguities contain their specific necessary clarification.
- Task completion: expected terminal status and bounded phase/call counts.
- Model quality: **not measured** by this run. Scripted valid choices are supplied.

Preserve existing exact-request admission, permission, cancellation, read-controller
and security tests. Changes to existing metadata-renderer expectations must require
readable facts by default and raw JSON only for explicit debug intent. The unwired
read controller remains unwired; synthetic seam coverage does not prove GUI,
packaged-app, production connector or release readiness.
