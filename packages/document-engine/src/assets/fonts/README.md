NotoSansCJKsc-VF.ttf is an unchanged official Noto Sans CJK SC variable TTF

ReportLab currently renders the font's default `wght=100` Thin outlines. The
SC face uses Simplified-Chinese regional glyph forms; language-tagged alternate
forms and weight-axis selection are not implemented. This asset provides glyph
coverage, not all-script shaping or all-Unicode support. Unsupported values
fail before an output is published. Keep both font licenses with their assets.
