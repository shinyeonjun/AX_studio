# Local folder

폴더는 경로가 아니라 연결된 저장소다. 주소를 조합해 넣지 않는다. 연결된 폴더와 파일은 조회해서 확인하고, 닿는 것만 쓴다.

이 일의 갈림은 거의 하나다.

- 지금 폴더에 있는 파일을 한 번 처리한다 → 시작은 수동이고, 확인된 파일을 가리킨다
- 앞으로 들어오는 파일마다 처리한다 → `local_folder.new_file`이고, 그때 생긴 파일을 넘긴다. 이미 있던 파일은 자동으로 돌지 않는다

둘 다처럼 들리면 그 선택만 묻는다. 확장자를 좁히는 것은 사용자가 말했거나 조회에서 드러난 뒤에 한다.
